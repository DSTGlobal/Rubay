# Rubay
Rubay — интернет-экосистема и торговая площадка, объединяющая ведущих производителей, дистрибьюторов и покупателей Краснодарского края. Платформа позиционируется как современное цифровое воплощение исторической Генуэзской торговой дороги, возрождающее торговые традиции Кубани в онлайн-формате.
